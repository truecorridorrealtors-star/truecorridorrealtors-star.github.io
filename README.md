# True Corridor Realtors — website

Static site (HTML/CSS/JS, no build step) for True Corridor Realtors, premium real estate advisory in Delhi NCR. Brand: Navy `#1B2A41`, Brass `#B4884A`, Stone `#D8D3CA`, Night `#0F1828`; type is Marcellus + IBM Plex Sans.

## Structure

```
index.html            home page (hero, advisory, verification process, corridors, enquiry form)
privacy.html          generated by build-pages.js
thank-you.html        generated, shown after a form submit (noindex)
404.html              generated, GitHub Pages serves it for missing URLs
assets/css/styles.css
assets/js/main.js     header on scroll, mobile menu, scroll reveal
assets/img/           logos + favicons from the brand kit
robots.txt, sitemap.xml, site.webmanifest
```

Edit the shared header/footer of the sub-pages in `build-pages.js`, then run `node build-pages.js`.

## Hosting (GitHub Pages)

1. Repo → Settings → Pages → Source: **Deploy from a branch**, branch `main`, folder `/ (root)`.
2. Custom domain: once the domain is bought, add it under Settings → Pages → Custom domain (this creates a `CNAME` file), and at the registrar add:
   - `A` records for the apex to `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `CNAME` for `www` → `<github-username>.github.io`
   Then tick **Enforce HTTPS**.
3. Until a custom domain exists, the site uses root paths (`/assets/...`) on sub-pages, so either name the repo `<github-username>.github.io` or use the custom domain.

Live at https://truecorridorrealtors-star.github.io/ . That URL is used in `index.html` (canonical, Open Graph, JSON-LD), `robots.txt` and `sitemap.xml`. When a custom domain is added, search-replace it with the new domain.

## Enquiry form

Uses [FormSubmit](https://formsubmit.co) → `truecorridorrealtors@gmail.com`. The **first** submission sends an activation email to that inbox; click the link once and later enquiries arrive automatically. Spam protection: honeypot field `_honey`.
